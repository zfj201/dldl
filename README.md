## 目录

| 路径 | 内容 |
|---|---|
| `input/sample.json` | 原始 APK 路径、大小、SHA-256；原文件未修改 |
| `apktool/` | Manifest、smali、资源 XML；跳过大体积 assets |
| `jadx/sources/` | Java 反编译结果 |
| `extracted/` | DEX、两种架构的 SO 和小型附属 assets |
| `recovered/runtime/` | 原始进程模块分段、哈希、映射和选定函数采集 |
| `recovered/*.memory.so` | 合并内存内容的分析映像，不能直接重新加载 |
| `recovered/libcocos2dlua.so.analysis.so` | 为 LLVM 反汇编制作的人工分析窗口，非完整修复 ELF |
| `recovered/plaintext/` | 已提取的明文资源索引 |
| `recovered/phase2/lua/` | APK 恢复的可读 Lua |
| `recovered/phase2/hotupdate/lua/` | 热更新恢复的可读 Lua |
| `modules/` | 八项日常任务、小助手接入与历史原型 |
| `tests/` | Lua 5.1 离线联调测试 |
| `evidence/` | ZIP／DEX／资源统计、地址、汇编与对象状态 |
| `scripts/` | 静态检查、只读内存采集、重建和后续捕获脚本 |
| `logs/` | 执行日志、错误记录 |
