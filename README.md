# 香香小助手扩展

为《斗罗大陆：武魂觉醒》华为渠道版提供的 LSPosed 模块。在游戏原有的香香小助手中增加日常任务和其他自动化，支持每天北京时间 **07:00** 自动启动游戏、进入主城并执行已开启的助手任务。

当前版本：**0.6.3**。无需 AutoJs、无障碍服务或图片模板，任务直接接入游戏内助手，可在原界面配置、执行和查看结果。普通手动打开游戏不会自动执行任务。

## 功能

### 日常任务

在香香小助手的“日常”分类中增加 17 项可独立开启的任务：

| --- | --- |

| 斗罗集市·每月礼包 | 领取每月免费礼包 |

| 积分赛·每日免费挑战 | 使用当前剩余免费挑战次数 |

### 其他自动化

在左侧“商店”下方新增同级分类 **“其他自动化”**，包含敏堂、极地矿场、联盟红包及敏堂历史入口。

**敏堂·自动派遣与刷新**

- 橙色、红色任务全部派遣。
- 绿色、蓝色、紫色任务，只派遣奖励包含钻石或斗魂挑战券的任务；白色任务不派遣。
- 先派完符合条件的任务，再按免费次数、敏堂刷新券、钻石的顺序刷新，循环筛选和派遣。
- 情报不足以继续派遣时停止；魂师条件不满足、刷新资源不足或状态无法确认时也会停止。
- 结果列表逐笔显示所有成功派遣，包括品质、名称、预计奖励、情报消耗和结束时间；可从历史入口再次查看。

**开启敏堂即允许消耗钻石刷新，当前不提供钻石消费上限。** 执行前请确认情报和钻石储备。派遣记录中的奖励为预计奖励，不代表已经领取。启用本项时，本次执行队列会排除原生敏堂刷新派遣任务，避免重复执行。

**极地矿场·每日挑战**

固定在 **50层1区** 选择可挑战矿点，优先选择符合条件的闲置矿点。使用已有三队伍进攻阵容，成功发起一次即完成，不等待结算，不自动占领或放弃矿点，不购买挑战次数。同一游戏日内已成功发起的任务，重启后也不会重复挑战。

**联盟红包·自动领取**

执行时刷新联盟红包列表和领取额度，按到期时间逐个领取当前可领的红包。自动跳过已领取、已过期、已被领完及达到当日领取上限的红包，结果页显示实际领取数量和钻石、金币汇总。每次运行均重新查询，同日再次执行可领取新出现的红包；不会自动发红包或购买红包。

### 定时运行与启动恢复

- 每天北京时间 **07:00** 启动游戏，处理已识别的可选更新、公告和华为推广，执行“开始冒险”，确认主城和绑定角色后运行已开启的完整助手列表。
- 提供“立即运行完整助手”“仅验证启动”和“30秒后验证定时启动”；两种验证模式均不执行助手任务。
- “健康游戏忠告”启动画面或华为初始化“正在加载中...”窗口连续停留超过 15 秒时，自动杀进程重启；切到后台或离开对应画面会重新计时，每次自动启动合计最多重试 3 次。
- 可设置助手完成后关闭游戏，也可随时停止自动运行；停止不会撤回已经发出的游戏操作。
- 按角色、服务器和北京时间 **05:00** 刷新的游戏日记录执行状态，防止同日重复执行完整队列。结果不明时保留记录，避免盲目重试资源消耗操作。

启动弹窗处理和加载恢复只在有效的自动启动流程中生效。强制更新、验证码、密码验证及未识别的阻塞页面需要人工处理。

## 运行要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Android 10 及以上，arm64 |
| 框架 | 支持现代 libxposed API 102 的 LSPosed 环境 |
| 游戏 | 华为渠道版，包名 `com.hnzh.dldlwhjx.huawei` |
| 定时运行 | 为“香香小助手扩展”授予 Root、精确闹钟及后台运行权限 |

当前适配上述渠道及已验证的游戏资源版本。其他渠道未适配；游戏更新、热更新或 SDK 变化可能影响功能，升级后建议先验证启动和单项任务。

## 安装与配置

1. 安装模块 APK，在 LSPosed 中启用“香香小助手扩展”，作用域仅勾选上述游戏，然后重启游戏。
2. 手动进入主城，打开游戏内香香小助手，在“日常”和“其他自动化”中选择任务、设置次数并保存。
3. 如需定时运行，打开模块配置应用，为**香香小助手扩展**授予 Root 权限，再点击“绑定当前角色（先手动进入主城）”。
4. 允许精确闹钟、运行通知、自启动和后台运行。小米等设备建议将模块省电策略设为“不限制”；使用冻结工具时也需放行模块。
5. 先点击“仅验证启动”，再通过“30秒后验证定时启动”检查后台唤醒。
6. 开启“每天北京时间 07:00 自动运行”，按需选择“助手完成后关闭游戏”。

敏堂、极地矿场和联盟红包需要分别开启并保存，才会加入定时执行队列。定时运行包含原助手已开启的其他分类，请同时检查原生任务的消费选项。

## 结果与常见问题

**在哪里查看结果？**

游戏内助手结果页显示逐项状态；敏堂提供逐笔派遣明细和历史入口。模块配置页的“刷新运行状态”可查看最近运行状态、精确闹钟权限和下次运行时间。

**为什么任务没有执行？**

先检查开关是否保存、玩法是否开放、阵容是否配置，以及资源或次数是否足够。已完成或当日额度已用完的任务会跳过；结果未确认的任务可能暂停，避免重复消费。

**为什么 07:00 没有启动？**

检查每日运行开关、角色绑定、Root、精确闹钟和后台权限，并排查系统省电或冻结工具。密码锁屏和登录验证可能需要人工介入。可用“30秒后验证定时启动”检查当前配置。

**如何停用？**

在模块配置页关闭每日自动运行；需要立即中止时点击“停止自动运行”。完全停用扩展时，在 LSPosed 中关闭模块并重启游戏。任务偏好和执行记录会保留。
