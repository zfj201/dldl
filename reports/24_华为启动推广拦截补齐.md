# 华为启动推广拦截补齐

日期：2026-10-25；模块版本：0.5.1 / versionCode 7。

## 问题和实际原因

用户今日07:00启动被“签到福利开启 / 内容由华为游戏中心提供”的推广遮住。设备原始启动日志停在 `waiting / waiting_sdk_or_login`。真机复现确认它属于华为登录流程，窗口为 `com.huawei.hwid/com.huawei.hms.runtimekit.stub.HMSKitStandardC2NETransparentActivity1`，展示发生在华为自己的进程中，阻塞登录返回。游戏进程里的两个公告 getter Hook 不能覆盖它。

静态分析同时确认遗漏的三处公告启动器：JOS `NoticeTaskApiCall.a(Parcelable)`，以及账号 SDK `hwid.k.a(Parcelable,c,ResponseErrorCode,TaskCompletionSource)` / `hwid.ae.a(Parcelable,u,ResponseErrorCode,TaskCompletionSource)`。这些仅处理 `core.getNoticeIntent` 的可选推广，可传 Intent 或 PendingIntent；现已补 Hook，沿用 `startupRequest()` 的有效期、取消和启动终态限制。它们是补充覆盖，本次原始弹窗的实际解决路径是下面的正常关闭兜底，不能用 Hook 已安装日志代替拦截命中证据。

## 模块内正常关闭兜底

`AutomationService` 在本次300秒启动有效期内，每约3秒检查一次前台窗口。只有已识别的华为推广容器在前台时，才通过模块原有Root能力调用系统 `uiautomator dump --compressed` 读取原生控件树；不需要AutoJs、截图模板或额外开启无障碍服务，不扩大LSPosed作用域。

`HuaweiPromotion` 要求同时满足：

- 前台为上述确切华为组件，用户为0；该 Activity 的任务根为斗罗大陆包名，不能属于其他应用的华为登录任务。
- 控件包名为 `com.huawei.hwid`，同时包含 `com.huawei.hms.game:id/notice_img` 和文字为“本应用今日不再展示”的 `block_strategy_checkbox`。
- 唯一的 `com.huawei.hms.game:id/close_image` 可用、可点击、描述为“关闭”，边界有效且位于当前窗口内。

识别后取该关闭控件**当前边界**的中心，点击前重新核对窗口token、指令ID、有效期、取消和disabled标记。窗口变化则跳过并等待重新识别，不复用旧位置。广告主图、设置按钮和“今日不再展示”复选框都不会被点击。每次启动最多发送6次已识别关闭操作；未知窗口保留，检查失败也不打断既有15秒加载恢复和启动超时逻辑。

普通手动打开游戏没有自动化服务和有效指令，不关闭推广、不自动开始冒险或执行助手。配置保持每天北京时间07:00运行；助手队列、角色绑定和消费journal未改。Lua文件内容哈希未变化，仅APK/资源清单版本升级。

新增模块私有诊断：`files/promotion-close.log` 记录发送正常关闭或窗口变化；`files/last-launch.txt` 保存系统拉起游戏的回执，便于区分未拉起与广告阻塞。临时控件树文件位于模块私有cache，读取后删除，不长期保存页面内容。

## 验证

离线检查通过：

- `tests/test_huawei_promotion.sh`：使用脱敏的真实控件树，覆盖位置变化、错误任务/包/用户/组件、登录/支付控件、缺少广告标识、不可点击、重复关闭控件、异常边界、超长输入与实体声明拒绝。
- `tests/test_sdk_promotion.sh`：普通调用保留返回值和异常、有效指令跳过可选推广、外层调用继续、请求结束后的迟到响应及同进程下一轮。
- 既有启动指令、15秒加载恢复、启动状态机、助手去重及加载器回归。
- `:app:assembleDebug :app:lintDebug --offline`：真实libxposed API102编译通过，Lint无错误，保留原有8项警告。

真机使用 Redmi Note 12T Pro / Android15，仅运行 `verify`，不重新跑今日完整助手队列。华为对这两张推广设置当天最多各展示一次；最初未再出现广告的启动不能证明修复有效。为获得有效对照，临时备份并重置**仅本游戏两条推广的展示计数**，重载华为进程缓存；不清除账号数据、权限或用户设置。复现出与用户截图相同的“签到福利开启”及另一张“游戏梗百科”推广后，最终模块自动正常关闭两张推广，进入主城并返回 `verified / city_and_role_ready`。首次窗口正在变化时记录 `window_changed` 并安全跳过，之后两次 `promotion_close_sent`，没有人为代点关闭。

最终完成两次广告均可展示的冷启动：每次均自动发送两次正常关闭，返回 `verified / city_and_role_ready`，对应指令均未发送助手业务请求，结束后launch已清理、前台服务退出。普通手动冷启动对照中，可选更新保持展示，人工正常取消更新后原始华为推广也保持展示；没有自动关闭记录，也没有自动开始冒险。

测试结束已恢复原始两条推广计数，检查角色绑定、每日开关与完成后关闭游戏设置均与测试前相同。每天07:00精确预约保留，下一次为2026-10-26 07:00（北京时间）。退出测试游戏并返回桌面，控件树cache文件已删除。0.5.1最终APK已覆盖安装。

原始截图、私有指令和诊断工具仅留在gitignored的 `evidence/phase17/`；公开控件树夹具不含账号、角色或token。脱敏验收摘要见 `evidence/phase17_promotion_verification.json`。
